Video Bitrate Calculator

Calculate the video bitrate you need to hit a target file size, or work backwards from a bitrate to predict file size. Built for editors who need to fit a deliverable under an upload limit — or just want to know how big that export will be.

Math: file size (bits) = total bitrate (bits/sec) × duration (sec). Sizes use decimal megabytes (1 MB = 1,000,000 bytes), the convention used by YouTube, Vimeo, and cloud storage. A ~2% allowance for container overhead is included — encoders hit bitrate targets on average, so aiming at 100% of a hard limit often lands over it.
