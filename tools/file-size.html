Video File Size Estimator

Predict how big your exported file will be from its bitrate and duration — before you hit export. No more surprise 40 GB uploads or blown client delivery limits.

Sizes use decimal units (1 GB = 1,000 MB = 1,000,000,000 bytes), matching YouTube, Vimeo, Dropbox, and drive manufacturers. VBR encodes vary with content complexity — treat the result as a planning estimate, typically within ±5%.
